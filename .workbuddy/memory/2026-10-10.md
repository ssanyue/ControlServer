## 追加：第一版仍竖排 —— 真根因是全局 `input { width: 100% }`

**现象**（用户截图）：复选框居中、文字跑到最右**一字一行竖排**。

**根因**：`style.css` 的全局规则 `input, select, textarea { width: 100%; padding: 6px 10px; ... }`
**同样命中 `input[type=checkbox]`**。在 `display:flex` 行里 `flex-basis` 默认取 `width`，
于是复选框按 100% 宽参与布局、吃掉整行，把 `<span>` 挤到最小宽度 ⇒ 逐字换行（竖排）。
第一版只复位了 `margin`，**漏了 `width`**，所以没暴露。

**修法**（`web/src/App.vue` scoped）：复选框逐项复位 —— `width/height:14px`、`padding:0`、
`border:none`、`background:none`、`flex:0 0 auto`、`accent-color:var(--accent)`；
并给 `label.inline` 加 `white-space:nowrap` 兜底。已在样式处写明"别再把 width 删掉"。

**教训**：全局表单样式（`input{width:100%}`）会**静默波及复选框**；只要把复选框放进 flex 行，
必须先复位尺寸与 padding —— 这是"改一处、坏另一处"的典型。

## 追问：公钥丢失如何弥补（23:00）

**核查结论（读代码核准，未改代码）**：

- **公钥丢得起** —— 三个独立来源，任一存在即可恢复：
  ① **由私钥现推**（数学上唯一确定）：`LicenseSigner.DescribeKeyPair(私钥Pem)` → `(PublicKeyPem, Fingerprint)`；
  `SignWithSelfCheck` 本身也是现推（注释明写"不让调用方再传公钥文件"，避免拿错钥匙掩盖真因）。
  ② **源码** `src/ControlServer.Core/Licensing/VendorPublicKey.cs`（`Pem` + `Fingerprint` 两个 const）＋ git 历史。
  ③ **每份已交付的服务端 exe 内嵌**（`dist/win-x64` 等，已实测带的是当前厂商公钥）。
- **私钥丢不起** —— 不可由公钥反推。弥补只能走「换密钥全量切换」：
  `new-key` → 替换 `VendorPublicKey.cs` → 重编重发**全部**交付形态 → 用新私钥重签全部客户授权。
- **重要澄清**：**私钥丢失 ≠ 存量授权作废**。只要**不重编服务端**，已部署服务端仍认旧公钥，
  存量授权继续有效（永久授权可一直用下去），只是**再也签不出新的**（续期/换机/新客户都发不了）。
  作废是"换密钥"这个动作造成的，不是"私钥丢失"本身。

**⚠️ 缺口（未修）**：现有工具**没有"从已有私钥导出/回显公钥"这个动作** ——
CLI 只有 `new-key` / `gen` / `inspect`，`gen` 只印 `公钥指纹`、**不印公钥全文**
（`LicenseIssuanceResult.PublicKeyPem` 其实已返回，但没落到界面或文件）；GUI 亦无入口。
⇒ 手里只有私钥、想拿回公钥时，目前只能靠**源码**或**服务端 exe** 兜底。
补法很小：加一个 `show-key`（或 `export-key`）命令 / GUI 一行"导出公钥"按钮。已向用户提出，待拍板。

**预防结论**：**只需备份私钥**（多份、离线、异地）；公钥无需备份。
若日后按「私钥内嵌进签发工具」方案落地，则等价于**备份签发工具 exe**（它就是密钥载体）。

## 追问：私钥丢失后如何换密钥（23:06）

**核心结论**：**换密钥不需要旧私钥** —— `new-key` 就是 `LicenseSigner.GenerateKeyPair()` **凭空生成**，
与旧私钥无关 ⇒ **"私钥丢失"只是触发原因，流程与主动轮换完全一样**，不会因为丢了而变难。

**非破坏性实测**（临时目录 `.tools/rotate-dryrun`，已清理；**正式密钥未触碰**，仍是 10-09 07:59 那份）：
- 空目录 `new-key` → 退出码 **0**，打印新指纹 + 可整段粘贴进 `VendorPublicKey.cs` 的代码块；
- 对**已存在**的私钥文件 → **拒绝覆盖**，退出码 **1**。

与 Linux 包（`deploy/linux/build-linux.sh`）**。已补全为六个 `dist\` 目录：
