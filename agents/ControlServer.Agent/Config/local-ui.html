UDP 指令通道

这台机器唯一开着的入站端口（收关机 / 重启等指令）
关闭时客户端完全不绑定该端口 —— 但有一个例外（2026-10-14 起）： 没连上中心时这条通道会被强制开启（端口沿用这里填的值）， 因为中心不可达时"还能不能关机"更要紧。中心一旦连上，就回到这里的设置说了算。 通道是明文的（2026-10-13 起不再签名）：报文就是一行 DOWN / RESTART / + / - / 0 / 1， 任意来源都能发，只有黑名单里的来源被丢弃。 所以这条通道的端口不要暴露到不可信网络。 要彻底不听（连未连接时也不听），只能改本机服务参数 Agent:Tasks:Enabled=false。
