# 项目边界与术语

> 用途：一句话说明**这个项目依赖什么、不依赖什么**，以及文档/注释里出现的几个词到底指什么。

---

## 1. 本项目是独立项目

- 工作区 `D:\Project\zhongkong`，解决方案 `ControlServer.sln`。
- **不依赖、不联动任何外部桌面程序**：没有指向它的 `ProjectReference`，没有硬编码路径，
  不读它的数据目录，也不要求它存在。**把它删掉，本项目照样编译、照样运行。**
- 数据**全部自持**：默认落在 `%ProgramData%\ControlServer`，
  内含 `control.db`（SQLite）/ `config/` / `files/` / `images/` / `logs/`。
  端口、账号、配置、图片都归本项目自己管。

## 2. 术语

| 术语 | 含义 |
|---|---|
| **旧版** | 本项目所替代的**旧版单机桌面程序**（已废弃）。它只是**功能清单与配置格式的历史来源**；本项目与它无依赖、无联动。 |
| **旧版配置 / 历史格式** | 旧版写出的数据形状：`control_config.json`、`commands.json`、`.controlbak` 备份包。本项目**只保留读取能力**，用途是让既有数据做**一次性迁移**。 |
| **旧版规则** | 标注为"沿用 / 照旧版"的那些语义点。含义是：**这些行为已在本项目内固定并被测试钉死**，随意改动会让历史数据导入后行为静默漂移；要改必须同步 `ControlSettingsNormalizer` 的迁移分支与守门用例。 |

## 3. 两条使用纪律

1. **旧版的实现不是正确性判据。** 旧版自身的缺陷**不照抄**。
   已知实例：`TimerTime → TimerTimes` 的迁移在旧版是**死代码**（默认值写在属性初始化器里，
   导致每个按钮都命中迁移分支、旧值被静默丢弃）。本项目把默认值下移到清洗器以保住旧值，
   并配了守门用例 —— 这是**有意偏离**，不要"修回去"。
2. **新增任何对外部桌面程序的引用 = 违规。** 包括但不限于：`ProjectReference`、
   硬编码路径、读取它的数据目录、以及"必须先装它才能跑"的任何假设。
   `docs/` 下的历史方案文档中保留的旧版源码行数对照，属于**考古记录**，不构成依赖。
