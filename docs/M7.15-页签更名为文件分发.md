# M7.15 主页面「文件」→「文件分发」

> 一句话：页签名只说**对象**（文件），没说**这一页能干什么**（把文件发到客户端），
> 现场把它当成"管理服务器上的文件"的页面，找不到"发下去"的入口。改名。
> 只动文案，**页签 key（`files`）、组件名、文件名、接口路径一概不动**。

## 1. 改动

| 位置 | 改前 | 改后 |
| --- | --- | --- |
| `web/src/App.vue` 页签按钮 | `文件` | `文件分发` |
| `web/src/App.vue` 三处注释 | 「文件页」 | 「文件分发页」 |
| `web/src/components/FilesPanel.vue` 文件头注释 | 「文件」页 = 文件仓库 + 文件分发 | 「文件分发」页 = 文件仓库 + 新建分发任务 + 分发任务 |

**未动**：

- 页签 key 仍是 `files`（`web/src/tabState.ts` 的白名单、地址栏持久化、`activeTab === 'files'` 的分支全靠它）；
- 组件仍是 `FilesPanel.vue` / `FileRepoPanel.vue` / `DistributionPanel.vue`；
- 接口仍是 `/api/files/*`、`/api/distributions/*`；
- 页内三块标题不变：**文件仓库** / **新建分发任务** / **分发任务**。

## 2. 为什么不叫「文件管理」

页内确实有三块，只有一块是"分发"。但：

- 页面的**目的**是分发；仓库只是"发什么"的来源，回传（客户机回传的那一格）本质也是分发的反向；
- 叫「文件管理」会把这一页与"运维在服务器上管文件"混起来 —— 而真正的磁盘管理在
  `C:\ProgramData\ControlServer\files\`，不在这页；
- 页签名一旦与页内第一栏（**文件仓库**）撞名，人就会以为整页就是那一栏。

## 3. 实证（`.build/ui-m715-files-tab.py`，系统 Edge headless，1440×900）

```
[1] 页签 = ['控制台','编辑','定时','指令库','客户端','文件分发','远程桌面','收发日志0','系统日志121','授权','用户','设置']
[1] 「文件分发」位置 = 5（前一个 = 客户端）
[4] 页签行数 = 1（top 集合 = [63]）
[2] 页内 h2 = ['文件仓库（1 个文件 · 占用 1022.1 MB · 客户机回传 1 个）', '新建分发任务', '分发任务（最近 28 条）']
[3] 刷新后高亮页签 = 「文件分发」
[PASS]
```

五条判据都是能单独翻红的：

1. 有「文件分发」**且**没有只叫「文件」的（防"改名改成两个页签"）；
2. 点进去三块都在（防"标签改了、路由没改"）；
3. **刷新后仍停在这一页**（防"改名顺手把 `tabState.ts` 的白名单打断"—— 那种错只在
   "这个页签单独刷新"时出现，别的页签全正常）；
4. **页签栏仍是一行**（文案长了 2 个字，横向 flex 最容易在这里换行）；
5. 「远程桌面」仍在（防改错邻居）。
