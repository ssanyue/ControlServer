# M7.14 顶栏「挂起」＋ 列表「结束会话」

> 一句话：把远控窗口右上角那个 `✕` 挪到**全屏左侧**并改名「**挂起**」，再在机器列表里给"有会话的那台"加一个「**结束会话**」。
> 一个按钮的位置与名字，背后是"收起来"和"真结束"这两件事终于各有一个说得出口的词。

---

## 1. 改了什么

### 1.1 顶栏：`✕` → 「挂起」，挪到最左

```
改前：  [全屏] [收起参数] [重连] [断开] [✕]
改后：  [挂起] [全屏] [收起参数] [重连] [断开]
```

**为什么两处都改**（不只是"挪个位置"）：

- `✕` 的通用语义是"关掉 / 销毁"。而它其实是这几个按钮里**最安全**的一个（什么都不销毁，
  会话还留着，别人还在看）。现场点了会以为会话被结束了，于是**不敢点** ——
  最后改用「断开」来收窗口，而「断开」是会掐掉所有观众的。
- 最右端本来就是"危险动作"的位置（`断开` 在那里）。把一个安全的动作摆在最右边，
  等于让它和危险动作抢同一个位置语义。

### 1.2 列表：「结束会话」（只在**这台机器真有会话**时出现）

```
DESKTOP-9VFHRMA  在线  会话 推流中·H264     [接着看] [结束会话]
DESKTOP-1UKRNGI  离线                        [连接]
```

**它补的是「挂起」带出来的那个缺口**：挂起之后窗口没了，画面上一个按钮都没有，
而这一路**还在推流**（被控端仍在编码、那台机器唯一的一路会话名额仍被占着）。
原来想收掉它，唯一的路是"再点进去 → 点断开"—— 那要**先建立一次 4K 解码再来拆它**。
有这条缺口在，「挂起」就会被现场当成"半残功能"，最终还是回去点「断开」。

- 与窗口里的「断开」是**同一个动作**（结束会话，所有在看的人一起黑），只是不用先进窗口；
  所以措辞统一写「结束会话」，不另造一个词。
- 没有会话时**不画**（`v-if="sessionToResume(a.id)"`）：一个恒在的灰按钮会被读成"这台机器坏了"。

## 2. 实现要点

| 点 | 做法 | 不这么做会怎样 |
| --- | --- | --- |
| 函数名 | `closeWindow()` → `suspendWindow()` | 名字还叫"关窗口"，半年后没人记得它和「断开」的区别 |
| 列表结束会话 | `endSessionOf(agent)` 复用 `endSession()` | 再写一遍 stop + refresh，两处迟早不一致 |
| `stoppingIntentionally` | **只在这一路正好是"本窗口在看"时才置** | 无脑置上会顺手掐掉**别的机器**正在跑的重连 |
| 收尾 | `wasWatching` 时补 `teardownViewer()` + 清 `windowAgentId` | 窗口标题还挂着"推流中 · 12 fps"，而那一路上一个字都不会再来 |
| 行内布局 | `.rd-machine-actions` 加 `display:flex; gap:8px` | 两个按钮挤在一起（`flex: 0 0 auto` 只保证不换行） |

## 3. 实证（`.build/ui-m714-suspend.py`，系统 Edge headless）

```
[0] 清空后行内按钮 = ['连接']
[1] 顶栏按钮 = ['挂起', '全屏', '收起参数', '重连', '断开']
[2] 挂起后窗口数 = 0
[2] 挂起后行内按钮 = ['接着看', '结束会话']
[2] 挂起后中心会话数 = 1（streaming）
[4] 结束后行内按钮 = ['连接']
[4] 结束后中心会话数 = 0
[4] 结束后重连条 = 0 ｜ 窗口数 = 0
[4] 提示 = ['已结束会话「014751-a6d58da6」。']

[PASS] 挂起位置/名称、会话保留、挂起期间不重连、列表结束会话 —— 全部符合预期
```

判据逐条：

| 判据 | 为什么是这个判据 |
| --- | --- |
| 顶栏 `labels[0] == '挂起'` 且 `labels.index('挂起') < labels.index('全屏')` | 只断言"挂起存在"验不到"挪到左边" |
| `'✕' not in labels` | 防的是"新加一个、旧的忘了删"（两个按钮做同一件事） |
| 挂起后 `.rd-window` 数量 == 0 且**中心会话数 == 1** | 只验窗口消失的话，"顺带把会话也结束了"也能通过 |
| 挂起后行内按钮 == `['接着看','结束会话']` | 两个按钮都在，才说明"收起来"与"真结束"分得开 |
| 再等 6 秒无 `.rd-reconnect` | 挂起期间窗口关着，不该有谁在替不存在的观众烧带宽 |
| 结束后中心会话数 == 0 且行内按钮回到 `['连接']` | "结束会话"必须真的结束，且列表状态跟着回落 |
| 结束后无窗口、无重连条 | 结束不该把窗口/重连条弹出来（那说明走了 `scheduleReconnect`） |

截图：`.build/m714-1-bar.png`（顶栏顺序）、`m714-2-suspended.png`（挂起后的列表）、`m714-3-ended.png`。

回归：`.build/ui-m713-reconnect.py` 里"关窗口"的那一步已改成点「挂起」，整条流程仍全绿
（新建 / 接着看 / 热更改 / 主动断开）。
