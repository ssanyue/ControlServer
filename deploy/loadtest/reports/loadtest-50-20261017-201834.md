## 6. 这份报告不能说明什么

- 🔴 **测的是中心，不是被控端。** 假 Agent 不抓屏、不编码、不推真码流 ⇒ **不能**用它承诺"100 台 4K 远控"。真机每台还要各自跑抓屏与硬编（本机物理不可得）。
- 帧是随机字节：中心不解码只转发，对中心的压力真实，但**测不到浏览器解码**的开销。
- 没有采集 GC 次数 / GC 暂停 / 线程池队列长度（要 `dotnet-counters`，本工具不带）。
- 所有假机器都注册在目标实例的库里。**必须用临时数据目录起的实例**，跑完把那个目录删掉 —— 否则在线表里会留下 N 台不存在的机器。
- Linux / Docker 侧未在本轮覆盖（沿用既有挂账）。
